# Neuroscope

NeuroScope is an advanced viewer for electrophysiological and behavioral data (with limited editing capabilities): it can display local field potentials (EEG), neuronal spikes, behavioral events, and the position of the animal in the environment.

Developed by Lynn Hazan (main developer), Montel Laurent (qt3 to qt4/5 porting), David Faure (qt3 to qt4/5 porting), Michaël Zugaro (plugins, maintenance), Florian Franzen (blackrock support, maintenance) and Joscha Schmiedt (qt5 to qt6 porting), distributed under the GNU Public License v2.

**Note:** The port to Qt 6 is still in progress.
